# What's new in 0.12.0

<small>Published on 2026-10-15: Python SDK `rayito` 0.12.0, TypeScript SDK
`rayito` 0.12.0 and `rayd` 0.12.0.</small>

0.12.0 brings the **management dashboard**: see and govern your sandboxes
(quotas, cost, inventory, images, events) without leaving your AWS account.
Everything is optional and off by default: without instantiating or deploying,
there is no new call or resource.

There are no API-breaking changes.

## At a glance { #de-un-vistazo }

| What | Python | TypeScript | Cost |
|---|---|---|---|
| Dashboard services in the SDK | `Quotas`, `UsageCost`, `Fleet` (and their `Async*` versions) | `Quotas`, `UsageCost`, `Fleet` | $0 for reads; Cost Explorer only with `billed()` |
| Local dashboard | `rayito dashboard` | — (the CLI is Python) | $0; `--cost-explorer` and `--events-stack` turn on what costs money |
| Dashboard in your account | `OptionalStacks().deploy("dashboard", ...)` | `new OptionalStacks().deploy("dashboard", ...)` | ≈ $0 at rest, by usage |
| CloudWatch dashboard | `rayito dashboard cloudwatch`; `dashboard-cloudwatch` stack | `dashboard-cloudwatch` stack | $0 with fewer than 4 dashboards |
| Multiple accounts | `rayito dashboard --account NAME=<ARN>`; `dashboard-read-role` stack | `dashboard-read-role` stack | $0 |
| Quota alerts | `quota-alerts` stack | `quota-alerts` stack | ≈ $0.30/month for the metric |

The full table, with IAM and how to turn each feature off, is in
[Optional features](../optional-features.md).

## The dashboard { #el-panel }

- **[Management dashboard (SDK)](../funciones-opcionales/panel-de-gestion.md).**
  `Quotas` reads the applied quotas and the allocated memory against the
  region's quota; `UsageCost` the billed MicroVM cost and the per-sandbox
  estimate; `Fleet` the inventory, the images and the events, and the bulk
  actions (kill, suspend, resume), which require `allow_actions=True` /
  `allowActions: true`.
- **`rayito dashboard`.** A server on `127.0.0.1` with a build-free page,
  light and dark, over the `/api/v1` API. Read-only by default;
  `--allow-actions`, `--cost-explorer` and `--events-stack` enable the rest.
- **[Dashboard in your account](../funciones-opcionales/panel-en-tu-cuenta.md).**
  The `dashboard` stack serves the same page and API from a Lambda with a
  Function URL and Cognito sign-in, with separate read and action roles and an
  audit of every action. The `AuthMode=aws-iam` variant signs with SigV4 and
  rejects anything unsigned before running the function.

## Optional extras { #extras-opcionales }

The three live in [Dashboard: extras](../funciones-opcionales/panel-extras.md):

- **CloudWatch dashboard**: `rayito dashboard cloudwatch` prints the JSON
  without calling AWS and the `dashboard-cloudwatch` stack deploys it.
- **Multiple accounts**: a read-only view of other accounts through an assumed
  role (`dashboard-read-role` stack).
- **Quota alerts**: the `quota-alerts` stack publishes to SNS when the
  allocated memory crosses a threshold, once per crossing.

## Other changes { #otros-cambios }

- **The image variant is recognized with a closed catalog.** An image of your
  own that starts with `rayito-` (for example `rayito-my-app-caps-efs`) is no
  longer interpreted as a known variant. `volumes=` requires
  `rayito-base-caps-efs` when the variant is known.
- **`dashboard-cloudwatch`**: an empty `DashboardName` uses the stack's name,
  so deploying no longer clashes with a dashboard of your own named `rayito`.
  An already deployed stack keeps its name. The region of the widgets added
  with `IncludeOtlp` or `IncludeQuota` is also fixed.
- **Template shortcuts.** `Template.dnf_install()` and `Template.npm_install()`
  (`dnfInstall()` and `npmInstall()` in TypeScript) install system and Node.js
  packages in the image; `apt_install` now points to `dnf_install`. See
  [Templates](../funciones-opcionales/templates.md).
- **TypeScript SDK parity.** `SandboxHealth.imdsBlocked` says whether `rayd`
  blocked IMDS for the sandbox, `sbx.metadata` returns `create()`'s `metadata`
  and `rayito/e2b` exports the `Chart`, `ProcessInfo`, `WriteEntry` and
  `WatchHandle` types, with the same names as in Python.
- **Security.** `rayd` upgrades `rustls` to 0.23.46 for RUSTSEC-2026-0346
  through 0349.
- **`rayito doctor`** knows the 0.12 series: it requires the `rayd` from the
  `rayd-v0.12.0` tag for SDK 0.12
  ([Compatibility](../limits.md#compatibilidad-sdk-rayd-imagen)).

## How to upgrade from 0.11.x { #como-actualizar-desde-011x }

1. **Upgrade the SDK.**

    === "Python"

        ```bash
        pip install -U "rayito[cli]"
        ```

    === "TypeScript"

        ```bash
        pnpm add rayito@latest
        ```

2. **Republish your image on `rayd` 0.12.0**
   ([Images](../images.md#publicar-las-tres)). `rayito doctor` gives FAIL on
   the `compatibility` check with a 0.11 image.
3. **If you want the dashboard**, start with
   [Management dashboard](../funciones-opcionales/panel-de-gestion.md).

There are no incompatible changes in the public API from 0.11.x.
