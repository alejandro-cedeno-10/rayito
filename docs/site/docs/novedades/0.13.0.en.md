# What's new in 0.13.0

<small>Published on 2026-10-16: Python SDK `rayito` 0.13.0, TypeScript SDK
`rayito` 0.13.0 and `rayd` 0.13.0.</small>

0.13.0 brings to TypeScript what only Python had until now: the **`rayito`
CLI**, the **`rayito-mcp` MCP server** and the **local dashboard**. You run
them with `npx`, without installing Python, and they do the same as their
Python counterparts: same surface, same output and same exit codes.

There are no API-breaking changes. Everything that costs money is still off by
default.

## At a glance { #de-un-vistazo }

| What | Python | TypeScript | Cost |
|---|---|---|---|
| CLI | `rayito ...` (`pip install "rayito[cli]"`) | `npx rayito ...` or `npm install --global rayito` | $0; each command says what it calls |
| MCP server | `rayito-mcp` (`mcp` extra) | `npx -y -p rayito -p @modelcontextprotocol/server -p zod rayito-mcp` | one MicroVM while in use |
| Local dashboard | `rayito dashboard` | `npx rayito dashboard` | $0; `--cost-explorer` and `--events-stack` turn on what costs money |
| Version and runtime | `rayito --version` → `rayito 0.13.0 (python)` | `rayito --version` → `rayito 0.13.0 (node)` | $0 |

The full table, with IAM and how to turn each feature off, is in
[Optional features](../optional-features.md).

## The CLI in TypeScript { #la-cli-en-typescript }

- **[CLI](../cli.md).** The same commands as in Python: `doctor`, `template`,
  `agent template`, `events`, `domain`, `stack`, `image publish|prune|zip`,
  `sandbox` and `dashboard cloudwatch`. `sandbox connect` and `sandbox create`
  without `--detach` open a real terminal, and `sandbox proxy` exposes a
  sandbox port on `127.0.0.1`.
- **One definition of the contract.** The output format, the compatibility
  table, the `image` plans and the proxy vectors live in `testdata/` and both
  CLIs run them, so a difference between the two breaks CI.
- **`rayito --version`** prints the version and the runtime, so you know which
  of the two CLIs answers when you have both installed.

## The MCP server and the local dashboard { #el-servidor-mcp-y-el-panel-local }

- **[MCP server](../mcp.md).** `rayito-mcp` in TypeScript exposes the same six
  tools as the Python one, over stdio or with `--http` (loopback only).
  `@modelcontextprotocol/server` and `zod` are optional peers: without them
  `rayito` keeps working and the executable tells you which command to use.
- **[Local dashboard](../funciones-opcionales/panel-de-gestion.md).** `npx
  rayito dashboard` serves the same page and the same `/api/v1` contract as
  the Python one, with the same defenses and read-only by default
  (`--allow-actions`, `--cost-explorer`, `--events-stack`, `--account`).

## Other changes { #otros-cambios }

- **Timestamps in UTC.** The Python CLI wrote timestamps in the machine's local
  zone; they now come out in UTC (`2026-09-15 14:39:02+00:00`), like the
  TypeScript one. If your script parsed them with a fixed zone, check the
  parsing.
- **Stricter `rayito sandbox proxy`.** It trims only spaces and tabs from
  headers and validates the chunk size before forwarding it: a
  `Content-Length` with a stray trailing character is no longer read
  differently from a strict server.
- **`rayito doctor`** knows the 0.13 series: it requires the `rayd` of tag
  `rayd-v0.13.0` for SDK 0.13
  ([Compatibility](../limits.md#compatibilidad-sdk-rayd-imagen)).
- **Documentation in Spanish and English**, with Python and TypeScript tabs in
  the CLI, MCP and dashboard pages.

## How to upgrade from 0.12.x { #como-actualizar-desde-012x }

1. **Update the SDK.**

    === "Python"

        ```bash
        pip install -U "rayito[cli]"
        ```

    === "TypeScript"

        ```bash
        pnpm add rayito@latest
        ```

2. **Republish your image on `rayd` 0.13.0**
   ([Images](../images.md#publicar-las-tres)). `rayito doctor` gives FAIL on
   the `compatibility` check with a 0.12 image.
3. **If you use the TypeScript CLI**, start with [CLI](../cli.md).

There are no incompatible changes in the public API of 0.12.x.
