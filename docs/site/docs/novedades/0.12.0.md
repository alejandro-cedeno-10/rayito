# Novedades de 0.12.0

<small>Publicada el 2026-10-15: SDK Python `rayito` 0.12.0, SDK TypeScript
`rayito` 0.12.0 y `rayd` 0.12.0.</small>

0.12.0 trae el **panel de gestión**: ver y gobernar tus sandboxes (cuotas,
coste, inventario, imágenes, eventos) sin salir de tu cuenta de AWS. Todo es
opcional y está apagado por defecto: sin instanciar o sin desplegar, no hay
ninguna llamada ni recurso nuevos.

No hay cambios que rompan la API.

## De un vistazo

| Qué | Python | TypeScript | Cuesta |
|---|---|---|---|
| Servicios del panel en el SDK | `Quotas`, `UsageCost`, `Fleet` (y sus versiones `Async*`) | `Quotas`, `UsageCost`, `Fleet` | $0 las lecturas; Cost Explorer sólo con `billed()` |
| Panel local | `rayito dashboard` | — (la CLI es de Python) | $0; `--cost-explorer` y `--events-stack` activan lo que cuesta |
| Panel en tu cuenta | `OptionalStacks().deploy("dashboard", ...)` | `new OptionalStacks().deploy("dashboard", ...)` | ≈ $0 en reposo, por uso |
| Dashboard de CloudWatch | `rayito dashboard cloudwatch`; pila `dashboard-cloudwatch` | pila `dashboard-cloudwatch` | $0 con menos de 4 dashboards |
| Varias cuentas | `rayito dashboard --account NOMBRE=<ARN>`; pila `dashboard-read-role` | pila `dashboard-read-role` | $0 |
| Avisos de cuota | pila `quota-alerts` | pila `quota-alerts` | ≈ $0,30/mes por la métrica |

La tabla completa, con IAM y cómo apagar cada función, está en
[Funciones opcionales](../optional-features.md).

## El panel

- **[Panel de gestión (SDK)](../funciones-opcionales/panel-de-gestion.md).**
  `Quotas` lee las cuotas aplicadas y la memoria asignada contra la cuota de
  la región; `UsageCost` el coste facturado de MicroVMs y el estimado por
  sandbox; `Fleet` el inventario, las imágenes y los eventos, y las acciones
  masivas (matar, suspender, reanudar), que exigen `allow_actions=True` /
  `allowActions: true`.
- **`rayito dashboard`.** Un servidor en `127.0.0.1` con una página sin
  compilación, claro y oscuro, sobre la API `/api/v1`. De sólo lectura por
  defecto; `--allow-actions`, `--cost-explorer` y `--events-stack` habilitan
  lo demás.
- **[Panel en tu cuenta](../funciones-opcionales/panel-en-tu-cuenta.md).** La
  pila `dashboard` sirve la misma página y API desde una Lambda con Function
  URL e inicio de sesión de Cognito, con rol de lectura y rol de acciones
  separados y auditoría de cada acción. La variante `AuthMode=aws-iam` firma
  con SigV4 y rechaza lo no firmado antes de ejecutar la función.

## Extras opcionales

Los tres viven en [Panel: extras](../funciones-opcionales/panel-extras.md):

- **Dashboard de CloudWatch**: `rayito dashboard cloudwatch` imprime el JSON
  sin llamar a AWS y la pila `dashboard-cloudwatch` lo despliega.
- **Varias cuentas**: vista de sólo lectura de otras cuentas con un rol que se
  asume (pila `dashboard-read-role`).
- **Avisos de cuota**: la pila `quota-alerts` publica en SNS cuando la memoria
  asignada cruza un umbral, una vez por cruce.

## Otros cambios

- **La variante de imagen se reconoce con un catálogo cerrado.** Una imagen
  propia que empieza por `rayito-` (por ejemplo `rayito-mi-app-caps-efs`) ya
  no se interpreta como una variante conocida. `volumes=` exige
  `rayito-base-caps-efs` cuando la variante se conoce.
- **`dashboard-cloudwatch`**: `DashboardName` vacío usa el nombre de la pila,
  así que desplegar ya no choca con un dashboard propio llamado `rayito`. Una
  pila ya desplegada conserva su nombre. También se corrige la región de los
  widgets añadidos con `IncludeOtlp` o `IncludeQuota`.
- **Atajos de plantilla.** `Template.dnf_install()` y `Template.npm_install()`
  (`dnfInstall()` y `npmInstall()` en TypeScript) instalan paquetes del
  sistema y de Node.js en la imagen; `apt_install` ahora apunta a
  `dnf_install`. Ver [Plantillas](../funciones-opcionales/templates.md).
- **Paridad del SDK TypeScript.** `SandboxHealth.imdsBlocked` indica si
  `rayd` bloqueó IMDS para el sandbox, `sbx.metadata` devuelve los `metadata`
  de `create()` y `rayito/e2b` exporta los tipos `Chart`, `ProcessInfo`,
  `WriteEntry` y `WatchHandle`, con los mismos nombres que en Python.
- **Seguridad.** `rayd` actualiza `rustls` a 0.23.46 por RUSTSEC-2026-0346 a
  0349.
- **`rayito doctor`** conoce la serie 0.12: exige el `rayd` del tag
  `rayd-v0.12.0` para el SDK 0.12
  ([Compatibilidad](../limits.md#compatibilidad-sdk-rayd-imagen)).

## Cómo actualizar desde 0.11.x

1. **Actualiza el SDK.**

    === "Python"

        ```bash
        pip install -U "rayito[cli]"
        ```

    === "TypeScript"

        ```bash
        pnpm add rayito@latest
        ```

2. **Republica tu imagen sobre `rayd` 0.12.0**
   ([Imágenes](../images.md#publicar-las-tres)). `rayito doctor` da FAIL en
   la comprobación `compatibility` con una imagen 0.11.
3. **Si quieres el panel**, empieza por
   [Panel de gestión](../funciones-opcionales/panel-de-gestion.md).

No hay cambios incompatibles en la API pública de 0.11.x.
