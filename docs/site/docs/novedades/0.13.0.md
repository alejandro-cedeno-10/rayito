# Novedades de 0.13.0

<small>Publicada el 2026-10-16: SDK Python `rayito` 0.13.0, SDK TypeScript
`rayito` 0.13.0 y `rayd` 0.13.0.</small>

0.13.0 lleva a TypeScript lo que hasta ahora sólo tenía Python: la **CLI
`rayito`**, el **servidor MCP `rayito-mcp`** y el **panel local**. Se usan con
`npx`, sin instalar Python, y hacen lo mismo que sus equivalentes de Python:
misma superficie, misma salida y mismos códigos de salida.

No hay cambios que rompan la API. Todo lo que cuesta sigue apagado por
defecto.

## De un vistazo

| Qué | Python | TypeScript | Cuesta |
|---|---|---|---|
| CLI | `rayito ...` (`pip install "rayito[cli]"`) | `npx rayito ...` o `npm install --global rayito` | $0; cada orden dice qué llama |
| Servidor MCP | `rayito-mcp` (extra `mcp`) | `npx -y -p rayito -p @modelcontextprotocol/server -p zod rayito-mcp` | un MicroVM mientras se usa |
| Panel local | `rayito dashboard` | `npx rayito dashboard` | $0; `--cost-explorer` y `--events-stack` activan lo que cuesta |
| Versión y runtime | `rayito --version` (termina en `(python)`) | `rayito --version` (termina en `(node)`) | $0 |

La tabla completa, con IAM y cómo apagar cada función, está en
[Funciones opcionales](../optional-features.md).

## La CLI en TypeScript

- **[CLI](../cli.md).** Las mismas órdenes que en Python: `doctor`,
  `template`, `agent template`, `events`, `domain`, `stack`, `image
  publish|prune|zip`, `sandbox` y `dashboard cloudwatch`. `sandbox connect` y
  `sandbox create` sin `--detach` abren una terminal real, y
  `sandbox proxy` expone un puerto del sandbox en `127.0.0.1`.
- **Una sola definición del contrato.** El formato de salida, la tabla de
  compatibilidad, los planes de `image` y los vectores del proxy viven en
  `testdata/` y los ejecutan las dos CLI, así que una diferencia entre ellas
  rompe el CI.
- **`rayito --version`** imprime la versión y el runtime, para saber cuál de
  las dos CLI responde cuando tienes las dos instaladas.

## El servidor MCP y el panel local

- **[Servidor MCP](../mcp.md).** `rayito-mcp` en TypeScript expone las mismas
  seis herramientas que el de Python, por stdio o con `--http` (sólo
  loopback). `@modelcontextprotocol/server` y `zod` son peers opcionales: sin
  ellos `rayito` sigue funcionando y el ejecutable te dice qué orden usar.
- **[Panel local](../funciones-opcionales/panel-de-gestion.md).** `npx rayito
  dashboard` sirve la misma página y el mismo contrato `/api/v1` que el de
  Python, con las mismas defensas y de sólo lectura por defecto
  (`--allow-actions`, `--cost-explorer`, `--events-stack`, `--account`).

## Otros cambios

- **Instantes en UTC.** La CLI de Python escribía los instantes en la zona
  local de la máquina; ahora salen en UTC (`2026-09-15 14:39:02+00:00`), como
  en la de TypeScript. Si tu script los analizaba con una zona fija, revisa
  el análisis.
- **`rayito sandbox proxy` más estricto.** Recorta sólo espacios y tabuladores
  de las cabeceras y valida el tamaño de trozo antes de reenviarlo: un
  `Content-Length` con un carácter raro al final ya no se interpreta distinto
  que en un servidor estricto.
- **`rayito doctor`** conoce la serie 0.13: exige el `rayd` del tag
  `rayd-v0.13.0` para el SDK 0.13
  ([Compatibilidad](../limits.md#compatibilidad-sdk-rayd-imagen)).
- **Documentación en español e inglés**, con pestañas Python y TypeScript en
  la CLI, MCP y el panel.

## Cómo actualizar desde 0.12.x

1. **Actualiza el SDK.**

    === "Python"

        ```bash
        pip install -U "rayito[cli]"
        ```

    === "TypeScript"

        ```bash
        pnpm add rayito@latest
        ```

2. **Republica tu imagen sobre `rayd` 0.13.0**
   ([Imágenes](../images.md#publicar-las-tres)). `rayito doctor` da FAIL en
   la comprobación `compatibility` con una imagen 0.12.
3. **Si usas la CLI de TypeScript**, empieza por [CLI](../cli.md).

No hay cambios incompatibles en la API pública de 0.12.x.
