# Borrador de 0.8.0

!!! danger "Sin publicar"
    Borrador de las notas de la próxima 0.8.0. Lo que está en `main` aún no
    está en ningún paquete publicado, y el número de versión, los nombres y
    las cifras pueden cambiar antes de la release.

## En `main`

- **Un agente de código dentro del sandbox** (`ai-agent-core`, ADR-025):
  `sbx.agent.run()`, `.stream()` y `.prepare()` con
  [OpenCode](https://github.com/anomalyco/opencode), en Python síncrono,
  asíncrono y TypeScript. Sesiones, límites (`AgentLimits`), eventos en
  streaming, `abort()` y `AbortSignal`, y errores con `reason` cerrado
  (`AgentException`/`AgentError`).
  [Agente en el sandbox](../guias/agente-en-el-sandbox.md).
- **Presets de pasarela para modelos**: `bedrock_gateway`,
  `anthropic_gateway` y `openai_compatible_gateway` (`bedrockGateway`…),
  con `allow` restringido a los modelos elegidos. La credencial sólo pasa
  por la [pasarela de secretos](../funciones-opcionales/pasarela-de-secretos.md).
- **Telemetría opcional**: un span `rayito.agent.run` con atributos
  `gen_ai.*` y de tokens, sólo con `tracer_provider=`; nunca el prompt ni
  el texto.
- **Seguridad**: amenazas T29 (el agente) y T30 (su cadena de suministro)
  en [Seguridad](../security.md#agente-de-codigo-dentro-del-sandbox).
- **Precios**: la página [Precios](../cost.md) explica cada componente del
  precio de las MicroVMs, el pool y un agente (VM frente a tokens), con
  cada cifra marcada como precio de lista o medida.

## También en `main`

- **`AgentTemplate`** y la orden `rayito agent template build`: la imagen
  del agente con OpenCode, ripgrep y deepagents fijados por sha256, y un
  demonio de prefetch que, tras cada restauración, espera a que el guest se
  calme y precarga el binario
  ([Templates de agente](../funciones-opcionales/templates-de-agente.md)).
- **`PoolConfig.warmup`** con `agent_pool_warmup()` y, con `serve=True`, un
  `opencode serve` residente en cada plaza
  ([Pool](../pool.md#calentamiento-warmup-y-servidor-residente)).
- **El runtime deepagents** (`runtime="deepagents"` o
  `runtime=DeepAgents(entrypoint=...)`)
  ([Agente en el sandbox](../guias/agente-en-el-sandbox.md#deepagents)).
- **Aceptación en AWS real** (Q146–Q152 de `AWS_API_NOTES.md`): las cifras
  "Medido en AWS real" del
  [arranque rápido](../guias/agente-en-el-sandbox.md#arranque-rapido).
