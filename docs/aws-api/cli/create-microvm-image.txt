
create-microvm-image
^^^^^^^^^^^^^^^^^^^^


Description
***********

Creates a MicroVM image from the specified code artifact and base
image. The build is asynchronous — the image transitions from CREATING
to CREATED on success, or CREATE_FAILED on failure. Use
GetMicrovmImage to poll for completion.

See also: AWS API Documentation


Synopsis
********

     create-microvm-image
   --base-image-arn <value>
   [--base-image-version <value>]
   --build-role-arn <value>
   [--description <value>]
   --code-artifact <value>
   [--logging <value>]
   [--egress-network-connectors <value>]
   [--cpu-configurations <value>]
   [--resources <value>]
   [--additional-os-capabilities <value>]
   [--hooks <value>]
   [--environment-variables <value>]
   --name <value>
   [--tags <value>]

   [--cli-input-json | --cli-input-yaml]
   [--generate-cli-skeleton <value>]

Options
*******

"--base-image-arn" (string) [required]

   The ARN of the Lambda-managed base MicroVM image to build upon. Use
   ListManagedMicrovmImages to discover available base images.

   Constraints:

   * min: "1"

   * max: "2048"

   * pattern: "[^\s]+"

"--base-image-version" (string)

   The specific version of the base MicroVM image to use.

   Constraints:

   * min: "1"

   * max: "2048"

   * pattern: "[^\s]+"

"--build-role-arn" (string) [required]

   The ARN of the IAM role assumed during the image build process.
   This role must have permissions to access the code artifact and any
   required resources.

   Constraints:

   * min: "20"

   * max: "2048"

   * pattern:
     "arn:aws[a-z\-]*:iam::[0-9]{12}:role/?[a-zA-Z_0-9+=,.@\-_/]+"

"--description" (string)

   A description of the MicroVM image.

"--code-artifact" (tagged union structure) [required]

   The code artifact containing the application code and metadata for
   the MicroVM image.

   Note: This is a Tagged Union structure. Only one of the following top
     level keys can be set: "uri".

   uri -> (string)

      The URI of the code artifact, such as an Amazon S3 path or
      Amazon ECR image URI.

      Constraints:

      * min: "1"

      * max: "2048"

      * pattern: "[^\s]+"

JSON Syntax:

   }

   CloudWatch log group, or {"disabled": {}} to turn off logging.

     level keys can be set: "disabled", "cloudWatch".

      logGroup -> (string)

         Constraints:
