## Decisions

1. **Through today's public API, not `sbx.agent`.** `sbx.agent` is not merged; the tests drive the runtimes with `commands.run`, `SecretGateway` and `allow_internet_access=False`, which is exactly what `sbx.agent` will wrap. When it lands its own local tests can reuse the fixture and the driver.
2. **The key never touches a host file, an env var of the runner or a log.** `make local-bedrock-key` pipes the output of `dev/local/agent/mint_bedrock_key.py` into `/tmp/rayito-local-bedrock-key` inside the runner (tmpfs, `umask 077`, gone at `make local-down`). The fixture stores `Bearer <key>` in Floci's Secrets Manager and deletes it on teardown; only `rayd` reads it. Assertions about the key compute a boolean first so a failure never prints sandbox output that could contain it, and the dataclass field is `repr=False`.
3. **Skip without the key, fail on the wrong guest.** No key file means the maintainer did not opt in to the paid model call: skip. A key with the base guest (no `opencode`) is a misconfiguration: fail with the `make local-agent-up` hint, in both SDKs.
4. **One sandbox per module.** The guest hosts one sandbox at a time; one sandbox for all agent tests keeps the run to a few minutes and exercises session continuation on a warm VM.
5. **Limits as each runtime defines them.** OpenCode: `agent.build.steps` (the binary's schema: "Maximum number of agentic iterations before forcing text-only response"), asserted as at most `steps + 1` `step_start` events and fewer files than requested. deepagents: LangGraph `recursion_limit`, asserted as `GraphRecursionError`. Timeout: `commands.run(timeout=...)` raises the SDK timeout error and leaves no `sleep` behind.
6. **Abort covers the process tree.** The agent is asked to run `sleep 300` through its shell tool; after `handle.kill()` (and after a timeout) no `sleep 300` process of `user` may remain.
7. **Telemetry off by default** means Rayito injects no `OTEL_*`, `LANGSMITH_*` or `LANGCHAIN_TRACING*` variable and LangSmith reports tracing disabled inside the sandbox; with egress closed nothing could leave anyway.
8. **Model pinned to the spike's**: the `us.anthropic.claude-haiku-4-5-20251001-v1:0` system inference profile in us-east-1, the cheapest active Claude in the test account.
