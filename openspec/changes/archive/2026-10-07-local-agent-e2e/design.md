## Decisions

1. **Through `sbx.agent`, not raw commands.** The tests exercise the public API (`AgentSpec`, `AgentLimits`, `bedrock_gateway`, `stream`/`run`/`abort`) so they guard what users call.
2. **The key never touches a host file, an env var of the runner or a log.** `make local-bedrock-key` pipes `dev/local/agent/mint_bedrock_key.py` into `/tmp/rayito-local-bedrock-key` inside the runner (tmpfs, `umask 077`, gone at `make local-down`). The fixture stores `Bearer <key>` in Floci's Secrets Manager and deletes it on teardown; only `rayd` reads it. Assertions about the key compute a boolean first so a failure never prints sandbox output that could contain it.
3. **Skip without the key, fail on the wrong guest.** No key file means the maintainer did not opt in to paid model calls: skip. A key with the base guest (no `opencode`) is a misconfiguration: fail with the `make local-agent-up` hint.
4. **Stop the process tree from the SDK.** `rayd` signals process groups; the runtimes' shell tools run in their own sessions. The SDK already runs commands as the agent's uid, so it freezes the runtime (`SIGSTOP`), walks its descendants with `pgrep -P` freezing each, kills them, then kills the handle. Freezing first keeps the runtime from spawning while the tree is walked. It cannot touch other users' processes. The timeout is enforced inside `rayd`, where the descendants are already orphaned when the SDK learns about it, so that case needs a `rayd` change (follow-up) and stays a strict expected failure.
5. **Drain after an SDK limit.** A killed multi-threaded runtime lingers as a zombie whose open files (the run lock) close only when the last thread exits; `rayd` sends the end event only after reaping it. Consuming the handle to that event makes the next `run()` not `busy`.
6. **Limits asserted by reason and by the runtime being gone.** Whether a model makes all tool calls in one step is up to the model, so the number of files written is not asserted.
7. **Model pinned to the spike's** (Claude Haiku 4.5 system inference profile in us-east-1), overridable with `RAYITO_E2E_BEDROCK_MODEL`/`RAYITO_E2E_BEDROCK_REGION`.
