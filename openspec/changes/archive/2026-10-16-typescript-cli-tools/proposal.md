## Why

The `rayito` CLI, the `rayito-mcp` server and the local dashboard server exist
only in the Python package (extras `cli` and `mcp`). `cli.md` and the parity
checklist call a TypeScript CLI out of scope, and ADR-026 point 6 says the
Python CLI "remains the only CLI". A Node user has to install Python to deploy
a stack, list sandboxes or open the dashboard, and SDK parity stops at the
library. ADR-027 reverses that: TypeScript ships the three executables with
the same surface, and the contract between the two implementations is shared
data under `testdata/`, never two copies that can drift.

## What Changes

- **Phase 0 (this PR, docs and contract only, no TypeScript code):**
  ADR-027 in `ARCHITECTURE.md` (it supersedes point 6 of ADR-026 and records
  decision D8, no synchronous TypeScript API); this OpenSpec change;
  `testdata/cli/surface.json`, a golden of the Python CLI surface generated by
  `clients/python/tests/unit/cli/test_cli_surface.py`; `check_sdk_parity.py
  --cli`, a report that lists every golden command as pending with the phase
  that delivers it and does not fail CI yet; `cli.md` and the parity checklist
  stop saying a TypeScript CLI is out of scope.
- **Phase 1:** `bin` entries in the npm package, `defineCommand` over
  `node:util parseArgs`, console, error translation and exit codes, global
  options, and the priority A commands except `doctor`.
- **Phase 2:** `doctor` and the compatibility table moved to shared test data.
- **Phase 3:** `template`, `agent template build`, `events`, `domain`,
  `dashboard cloudwatch`.
- **Phase 4:** interactive terminal, `sandbox connect`, `exec -it` and
  `sandbox proxy`, with shared header-smuggling vectors.
- **Phase 5:** `image publish|prune|zip`.
- **Phase 6:** the MCP server with the official SDK as an optional peer.
- **Phases 7 and 8:** the dashboard `/api/v1` core and the local server, with
  shared vectors for the contract, the guard, the security headers and the
  theme.
- **Phase 9:** documentation with Python/TypeScript tabs, cost declaration and
  CHANGELOG.

## Impact

- New capability requirements in `cli`, `mcp-server`, `typescript-sdk` and
  `architecture-docs`. The dashboard requirements are specified in the change
  that introduces the dashboard (`dashboard`); phases 7 and 8 extend it once
  that change is archived.
- No change to `rayd`, the `.proto` or the Python public API. `exports` of the
  npm package does not change; `bin` is the only new package field.
- Everything that costs AWS quota stays off by default (ADR-014).
